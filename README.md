# Paradise Nursery - e-plantShopping

Paradise Nursery is a plant shopping application built with React, Redux Toolkit, and Vite.

## Features

- Browse plants across five different categories.
- View plant images, descriptions, and prices.
- Add plants to the shopping cart.
- View the total quantity of items in the cart.
- Increase or decrease item quantities.
- Remove plants from the cart.
- Calculate individual item totals and the overall cart total.
- Continue shopping after viewing the cart.

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Vite
